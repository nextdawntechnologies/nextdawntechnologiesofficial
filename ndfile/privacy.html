Privacy Policy

Effective July 16, 2026 · Published by Next Dawn Technologies

ND File is local-first. It does not require an account, sell data, or track you across apps.

We Do Not Collect Your Media Data

ND File has no service that collects user data and includes no advertising or third-party analytics SDK. The developer does not receive your files, file names, media index, playback history, favorites, server addresses, or diagnostic logs. App Store handles membership payments; the app receives only a verified StoreKit entitlement and never receives full payment details.

Data Stays on Your Device

The media index, playback progress, favorites, and settings are stored in the app's local database. Folder permissions are managed by the operating system. Passwords are protected by iOS Keychain or Android Keystore. Removing a source deletes its saved credentials; other retention follows your operating system's rules.

Only Sources You Choose Are Accessed

ND File accesses content only after you choose a folder or configure a network source. Network connections go directly from this device to the server you configure (for example your own NAS over SMB, WebDAV, SFTP, FTP, or NFS). You or the server operator control how that server handles data.

You Control and Can Delete Local Data

You can remove sources and delete playback history, caches, and diagnostic logs. Revoking access does not modify original media. ND File never uploads diagnostic logs; they leave the device only when you explicitly export them with the system share sheet.

Policy Updates and Contact

If these practices materially change, a new app version will update this notice. For privacy questions, contact the developer at nextdawntechnologies@gmail.com.

ND File はローカルを優先するアプリです。アカウントを必要とせず、データを販売したり、アプリをまたいでユーザーを追跡したりすることもありません。

メディアデータを収集しません

ND File にはユーザーデータを収集するサービスがなく、広告 SDK や第三者の分析 SDK も含まれていません。開発者がファイル、ファイル名、メディアインデックス、再生履歴、お気に入り、サーバーアドレス、診断ログを受け取ることはありません。メンバーシップの支払いは App Store が処理し、アプリが受け取るのは StoreKit で検証済みの利用権限のみです。支払い情報の全詳細を受け取ることはありません。

データはデバイス上に保存されます

メディアインデックス、再生位置、お気に入り、設定は、アプリのローカルデータベースに保存されます。フォルダへのアクセス権限は OS が管理します。パスワードは iOS Keychain または Android Keystore で保護されます。ソースを削除すると、保存された認証情報も削除されます。それ以外のデータ保持は OS の規則に従います。

選択したソースにのみアクセスします

ND File は、フォルダを選択するかネットワークソースを設定した後にのみ、コンテンツにアクセスします。ネットワーク接続は、このデバイスから設定したサーバーへ直接行われます（例：SMB、WebDAV、SFTP、FTP、NFS を使った自分の NAS への接続）。サーバーでのデータの扱いは、ユーザーまたはサーバー運営者が管理します。

ローカルデータを管理・削除できます

ソースを削除し、再生履歴、キャッシュ、診断ログを消去できます。アクセス権限を取り消しても、元のメディアは変更されません。ND File が診断ログをアップロードすることはなく、システムの共有シートから明示的に書き出した場合にのみ、ログがデバイスの外に送信されます。
